# Privacy (stub)

NDPR-aligned privacy-by-design per PRD §45. Full policy text and DSAR flows complete by Phase 9–10.

## Principles

- Collect only required personal data
- Users can access, correct, export, and request deletion (subject to lawful retention)
- Consent + granular communication preferences
- Exact addresses never in browse/search payloads
- Identity documents: store provider references / hashes only — never raw NIN/BVN in logs or public UI

No personal data processing in app code yet. Update this doc when Auth (Phase 1) ships.
